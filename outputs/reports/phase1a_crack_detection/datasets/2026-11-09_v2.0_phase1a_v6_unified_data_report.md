## 2. PHÂN TÍCH CHI TIẾT 4 THUỘC TÍNH ĐỒNG BỘ TRONG DATASET

Toàn bộ **49,804 ảnh** trong bộ V6 đều được chuẩn hóa đồng bộ 4 thuộc tính (Dual-Export đa nhiệm, tổng cộng 199,216 files + data.yaml):

```
v6_unified_crack/
├── images/        [Thuộc tính 1: Ảnh gốc RGB]
├── masks/         [Thuộc tính 2: Mặt nạ nhị phân Binary Mask]
├── centerlines/   [Thuộc tính 3: Trục xương vết nứt 1-pixel Skeleton]
└── labels/        [Thuộc tính 4: Tọa độ đa giác YOLO Polygon .txt]
```

### Chi tiết từng thuộc tính:
1. **`images/` (Ảnh gốc RGB):**
   - Định dạng: `.jpg` / `.png`.
   - Độ phân giải: Đa dạng từ 448x448, 512x512, 640x512 đến 800x800 pixel.
2. **`masks/` (Binary Mask):**
   - Giá trị pixel: `0` (Nền & hư hỏng không phải nứt) và `255` (Vết nứt bê tông).
   - Dùng trực tiếp cho: **SegFormer, BiRefNet, Mask2Former, U-Net, DeepLabV3+**.
3. **`centerlines/` (Trục xương vết nứt 1-pixel):**
   - Giá trị pixel: `0` (Nền) và `255` (Trục tâm vết nứt rộng đúng 1 pixel).
   - Được sinh đồng bộ 100% bằng thuật toán hình thái học **Guo-Hall / Zhang-Suen Thinning** (`skimage.morphology.skeletonize`).
   - Dùng trực tiếp cho: **Hàm loss clDice / clIoU (Centerline Dice)** và đo đạc chiều dài vết nứt.
4. **`labels/` (Tọa độ đa giác YOLO Polygon):**
   - Định dạng: file văn bản `.txt` với cấu trúc `0 x1 y1 x2 y2 x3 y3 ...` (tọa độ chuẩn hóa `[0, 1]`).
   - Dùng trực tiếp cho: **YOLOv11m-seg, YOLO26-seg, YOLOv8-seg**.

## 3. PHÂN TÍCH CHUYÊN SÂU: CÓ NÊN THÊM THUỘC TÍNH NỮA KHÔNG?

> [!NOTE]
> **Đánh giá câu hỏi: "Có phải càng nhiều thuộc tính thì kết quả càng cao?"**
> Việc thêm thuộc tính chỉ phát huy tác dụng khi:
> 1. Thuộc tính đó bổ sung thông tin trực giao (orthogonal information) mà ảnh gốc chưa thể hiện rõ.
> 2. Kiến trúc mô hình có thiết kế nhánh tiếp nhận (Auxiliary Branch / Multi-task Head) để khai thác thuộc tính đó.

### Đề xuất 3 thuộc tính tiềm năng mở rộng:

| Thuộc tính đề xuất | Cách biểu diễn | Lợi ích cho mô hình | Đề xuất triển khai |
|---|---|---|---|
| **1. `crack_width_map` (Bản đồ phân bố bề rộng)** | Ảnh Grayscale Float32 biểu diễn khoảng cách từ tâm nứt đến biên (Euclidean Distance Transform). | Giúp mô hình phân biệt vết nứt bề mặt siêu nông (<0.2mm) với vết nứt xé toạc kết cấu (>1mm). Cực kỳ quan trọng cho Phase 2 (Severity Classification). | **NÊN TÍNH ONLINE TRONG DATALOADER** (không lưu tĩnh ra đĩa để tránh tốn thêm 15GB bộ nhớ). |
| **2. `domain_surface_tag` (Nhãn vật liệu)** | Mã danh mục: `concrete_beam`, `concrete_wall`, `pavement_road`, `masonry_brick`. | Giúp mô hình thích ứng miền (Domain Adaptation), không báo nhầm khe co giãn mặt đường sang nứt dầm. | **ĐÃ CÓ SẴN QUA PREFIX TÊN FILE** (`csd_`, `dam_`, `roads_`, `BCL_`, `TopoDS_`). |
| **3. `crack_orientation_map` (Bản đồ hướng nứt)** | Góc nghiêng $\theta \in [0, 180^\circ]$ của từng đoạn nứt. | Vết nứt xiên 45° cảnh báo đứt gãy cắt cốt đai, nứt đứng cảnh báo quá tải uốn. | **DÀNH CHO PHASE 3 (SHM ENGINE)** khi trích xuất vector kỹ thuật kết cấu. |

👉 **KẾT LUẬN VỀ THUỘC TÍNH:**  
Bộ 4 thuộc tính hiện tại (`images`, `masks`, `centerlines`, `labels`) là **chuẩn mực SOTA hoàn chỉnh nhất hiện nay**, cân bằng hoàn hảo giữa dung lượng lưu trữ (11GB) và hiệu năng huấn luyện cho mọi họ mô hình (YOLO, Transformer, CNN).

## 4. QUY TRÌNH TIỀN XỬ LÝ DỮ LIỆU ĐÃ THỰC HIỆN (PREPROCESSING PIPELINE)

1. **Khử trùng 3 tầng (Deduplication):** Loại bỏ 65 ảnh trùng lặp giữa OmniCrack30k và CSD/DeepCrack bằng thuật toán DCT pHash 64-bit + MD5.
2. **Khắc phục rò rỉ dữ liệu (Anti-Leakage):** Cô lập 6 ảnh bị leak giữa train OmniCrack và test hiện tại, giữ tập Test hoàn toàn độc lập 100%.
3. **Thanh lọc tạp chất nhãn (Artifact Cleaning):** Loại bỏ triệt để hơn 17.4 triệu pixel bong tróc, xói mòn, ố vàng từ BFDD về nền 0.
4. **Tạo trục xương tự động (Skeleton Thinning):** Sinh đồng bộ `centerlines` cho 19,971 ảnh chưa có bằng `skeletonize`.
5. **Chuyển đổi đa giác (Polygon Extraction):** Sinh 24,913 nhãn polygon chuẩn YOLO cho toàn bộ ảnh mới.
6. **Kiểm tra tính toàn vẹn (Integrity Check):** Loại bỏ file 0-byte và file ảnh lỗi đọc.

## 5. HƯỚNG DẪN HUẤN LUYỆN 4 MÔ HÌNH SOTA TRÊN KAGGLE (GPU T4 X2)

Sau khi upload file `.zip` lên Kaggle, bạn có thể triển khai huấn luyện theo 4 hướng sau:

### Hướng 1: SegFormer-B5 (`nvidia/mit-b5` — Khuyên dùng số 1)
- **Tập dữ liệu dùng:** `images/` và `masks/`.
- **Hàm Loss:** Combo `DiceLoss(smooth=1.0) + FocalLoss(alpha=0.25, gamma=2.0)`.
- **Số Epochs:** **10 – 15 epochs** (hội tụ cực nhanh).
- **Mã lệnh mẫu (PyTorch):**
  ```python
  from transformers import SegformerForSemanticSegmentation
  model = SegformerForSemanticSegmentation.from_pretrained(
      "nvidia/mit-b5",
      num_labels=2,
      id2label={0: "background", 1: "crack"},
      label2id={"background": 0, "crack": 1},
      ignore_mismatched_sizes=True
  )
  ```

### Hướng 2: BiRefNet (`ZhengPeng7/BiRefNet` — SOTA Biên Mỏng 2024)
- **Tập dữ liệu dùng:** `images/` và `masks/` (kích thước input chuẩn 1024x1024 hoặc 768x768).
- **Đặc điểm:** Tinh chỉnh 8 epochs là đạt biên cực kỳ sắc nét.
- **Mã lệnh mẫu:**
  ```python
  from transformers import AutoModelForImageSegmentation
  model = AutoModelForImageSegmentation.from_pretrained("ZhengPeng7/BiRefNet", trust_remote_code=True)
  ```

### Hướng 3: YOLO26-seg / YOLOv11m-seg (Real-Time Edge)
- **Tập dữ liệu dùng:** Trỏ file `data.yaml` vừa sinh sẵn trong thư mục V6.
- **Mã lệnh mẫu (Ultralytics):**
  ```python
  from ultralytics import YOLO
  model = YOLO("yolo11m-seg.pt")
  model.train(
      data="/kaggle/input/v6-unified-crack/data.yaml",
      epochs=60,
      imgsz=800,
      batch=16,
      optimizer="SGD",
      lr0=0.01,
      close_mosaic=10,
      device=[0, 1]
  )
  ```

### Hướng 4: nnU-CrackNet / SMP U-Net ConvNeXt-V2 + clDice Loss (Bảo toàn Topology)
- **Tập dữ liệu dùng:** `images/`, `masks/`, và `centerlines/`.
- **Hàm Loss:** $\mathcal{L} = 0.5 \mathcal{L}_{Dice} + 0.3 \mathcal{L}_{Focal} + 0.2 \mathcal{L}_{clDice}$.
- **Mục tiêu:** Đạt clIoU $> 70\%$ trên tập Test.
